# Build and learn: AI engineering experiments

Small, runnable experiments with explanations and hands-on exercises. Lessons are scheduled every two days. We discuss concepts first and publish an experiment after the learner is ready.

| Experiment | What you learn |
| --- | --- |
| [001: Document search](experiments/001-document-search/README.md) | Tokenization, word counts, cosine similarity and retrieval |
| [002: Answer from evidence](experiments/002-evidence-shopping/README.md) | Product identity, source attribution, missing evidence and evaluation |

Start with experiment 001. Each folder contains its own setup instructions, code and learning exercise.
