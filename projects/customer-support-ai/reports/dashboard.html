What we learned

ChallengeKeyword routing missed paraphrases. Model routing sometimes confused product questions, return conditions, and exact dates.
ResponseAdded scope checks, deadline cues, order-status normalization, and a safe fallback to verified policy evidence.
DecisionThe numeric prototype gate passed, but one mixed question was not clearly split. Keep the classifier experimental until broader evaluation.

Remaining mismatch

“Are these appropriate for cycling, and can they be sent back?” was refused as unsupported. It did not get an incorrect return answer, but the better response would ask the shopper to split the product question from the return question.

Next: test more mixed product-use and return wording, ideally reviewed by someone who did not write the prompt.

The project does not connect to real orders, authenticate customers, execute refunds, or run as a public website. Source and detailed results: GitHub project · v10 results.
